# 交大课表 1.14.26 · A 分支后续测试版

在已发布的 1.14.25 基础上修复常用网站共用 WebView 的导航问题，保留此前课表、日程、界面、配色及数据逻辑。本次覆盖原测试 Release 的 1.14.25 附件；测试分支更名为 `test/1.14.26`，测试标签更新为 `v1.14.26-test`。保留原测试提交历史，保持 Pre-release，不替代正式 Latest。

## 本次修复
- 重试重新加载实际失败的目标 URL，不再无条件返回网站初始主页。
- 新导航、SPA 地址变化和重试会使旧异步任务失效，忽略过期加载完成和错误回调。
- 自动 SSO 引导限定在首次入口及明确登录页面，执行前核对当前文档，避免内容页被旧认证工作覆盖；保留正常登录和合法重定向。
- 图书馆重试保留已接受的 HTTP 回退状态；邮箱/图书馆子框架导航不再提升为整个 WebView 的重载。
- 保留原生网页历史、Cookie 和会话；移除返回后的 900 ms 导航锁，不增加固定延迟或 URL 锁定。

## 安装
- versionName：`1.14.26`；versionCode：`82`。
- 包名 `cn.sjtu.jiaotong_course.slimtest.a`，应用名「交大课表·测试A」，沿用测试签名，可覆盖安装 1.14.25 测试 A，并与正式版并行安装。
- 常见手机选 `arm64-v8a.apk`；架构不确定选 `universal.apk`。另提供 ARM32 和 x86_64。
- 附件含源码、验收记录、包校验结果与 SHA256SUMS，不含签名私钥、本机缓存和账号凭据。

## 已验证与待测
- 236 项 Flutter 测试通过，其中包含全部 9 个内置网站、浅色/深色主题的 24 项受控 WebView 测试；另有 12 项 JavaScript 检查通过，Flutter analyze 无问题。
- 四个 APK 的版本、ABI、测试签名及 ZIP 完整性检查通过。
- **用户明确安排真机稍后测试。** 尚未验证真实 Android 安装运行、水源真实帖子停留 10 秒、真实 SSO/Cookie、网络断开恢复及系统返回手势；受控组件的虚拟时间不能当作真实网站验证。
- 根因来自实际代码缺陷和受控复现；没有手机现场日志，尚不能确定用户当时匹配的具体 DOM 控件。详细证据及逐站状态见 `1.14.26-VERIFICATION.md`。
- 1.14.25 的已知限制仍存在：后台 Canvas 检查采用 15 分钟周期并可能受系统延迟，未实现严格后台每 2 分钟；邮箱自动收信尚未接通。本次没有修改消息同步功能。
