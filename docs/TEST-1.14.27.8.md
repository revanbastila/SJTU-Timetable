# 交大课表 1.14.27.8 · A 测试版

版本 1.14.27.8（95），包名 `cn.sjtu.jiaotong_course.slimtest.a`，沿用测试 A 签名，可覆盖安装 1.14.27.7。

## 修正

1.14.27.7 在荣耀 Magic8 Pro 上能切到 PPT，但复制 Activity 窗口时持续得到黑帧，无法识别二维码。本版改为从应用自身的 FlutterSurfaceView 采集，并将 WebView 内视频范围映射至 Flutter 实际布局坐标，计入导航栏、课程信息及提示区域的偏移。

仅在当前应用中可见的直播画面范围采集；截图继续在内存中交由原生 ZXing 解码。保留 PPT／电脑画面优先、单屏、手动选择、失败回退、签到确认和课程／任务匹配规则。没有引入模拟服务器、模拟账号或模拟提交代码；没有放宽学校连接的 HTTPS 限制。

## 验证与限制

合入后的应用通过 328 项 Flutter 回归和 23 项播放器 JavaScript 检查，静态分析无问题；新增坐标映射测试覆盖顶部偏移、横屏侧向偏移和过期越界范围。

2026-10-27，同一部荣耀 Magic8 Pro（Android API 36）上的独立模拟包完成 12/12 项测试：44 次原生采样、35 次解码、10 次本地模拟请求，采样错误为 0。覆盖桌面及移动播放器、浅色及深色和主题切换、过期码轮换、去重、网络失败、模拟课程不匹配、手动选择、无入口回退、切换失败无二维码、取消后阻止提交。无入口回退时播放器控制栏仍可能遮住部分画面，严重遮挡时可手动调整播放器。

这些真机结果来自隔离模拟包；本版合入相同的原生采样和坐标映射代码。模拟课程匹配与提交结果由本地适配器提供，未调用学校签到提交接口。**真实课堂页面、学校服务端提交及结果回读的完整签到仍待验收**，不能将模拟通过等同于真实课堂签到成功。

首轮切换失败负例仍在可见 PPT 小窗显示二维码，应用按回退规则识别成功，与“无二维码、零提交”的预期冲突。已保留该轮证据，将负例两个可见视频都设置为无二维码教师画面后，重新执行全部 12 项并通过。
