# 交大课表 1.14.27.3 · A 测试版

沿用现有 `test/1.14.26` 测试分支及 A 测试包，保留迭代历史。本次更新测试预发布附件；正式 main、正式标签和正式 Latest 保持不变。

## 修改
- 修复真实学生签到记录读取：通过 Canvas 当前课程的真实“点名签到”LTI入口和 `/sign/records/` 接口，按发起时间、本人状态与课程窗口判断；不再将教师发起接口作为学生查询前置条件。
- 保留课前10分钟至课后10分钟的有效范围、连堂合并、现有课程映射和校历规则，持久化去重，区分已签到、历史未签到、未知开放状态、无入口和认证/网络失败。
- 增加窗口内原生 Android dataSync 前台服务，以30秒为目标间隔，使用必要的常驻通知和课程边界闹钟；前后台交接共享请求限制，课外停止。首次/失效课程会话通过正常Canvas LTI尝试建立，认证失败退避，不处理验证码。
- 用户确认后进入实际课程“课堂视频新版”直播，验证播放并捕获应用内视频区域，连续识别动态二维码；确认课程与任务关联后才允许提交，并重读本人记录确认结果。
- 修复直播打开失败/超时后的待办释放，避免旧任务阻塞后续签到。保留此前WebView、课表、界面与其他功能修改。

## 重要限制：未完成端到端验收
- **真实课程窗口内后台30秒运行、新发签到通知/弹窗、当前直播二维码、任务关联、最终提交及成功回读仍未实测通过。自动化测试和编译成功不代表自动签到已可用。**
- 学生记录ID与二维码signHistoryId不能混用，序号不是任务ID；学生任务详情是否提供必要关联字段尚未确认。不能确认关联时停止提交并提示在学校页面核实，不盲目签到。
- 首次/失效会话的不可见LTI自恢复未单独制造失效验收；遇到学校验证码、二次验证或权限不足，需要本人处理。
- Android后台以系统通知进入执行弹窗，不强行覆盖其他应用；没有绕过学校验证或受保护视频。
- 省电、休眠、网络、强停和后台启动限制可能影响30秒间隔。Android 15+ dataSync 后台运行存在6小时/24小时时限；达到时限或不能启动时退回系统周期任务（最短15分钟），不能保证永久严格30秒。
- Canvas公告仍不是实时事件推送，邮箱自动收信尚未接通。本次没有宣称解决这些既有限制。

[Android服务时限](https://developer.android.com/develop/background-work/services/fgs/timeout) · [后台启动限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)

## 发布打包说明

通用包及未压缩分架构包上传时，连接在数据传输结束后反复被重置，未创建成功的APK附件。改用Android Gradle标准 `packaging.jniLibs.useLegacyPackaging=true` 后，分架构包缩小下载体积；手机包进一步无损优化 ZIP 的 Deflate 压缩并使用同一测试证书重新签名，最终均小于10MB并已上传；只改变安装容器与原生库解压方式，不改变Dart/DEX或原生库内容。不把压缩包二进制一致性核验当作新的端到端运行验收。

ARM64容器进一步无损压缩，所有DEX与原生库内容与已测通用包逐文件一致。可复现工具：`tools/optimize_test_apk.py`，构建依赖`zopfli==0.4.3`，输出无签名APK后应使用Android SDK zipalign及自己的测试密钥重新签名。此工具不随应用运行，不处理账号或会话。

本次Release仅提供手机ARM64/ARM32安装包。通用包和x86_64包在当前网络上传未成功，因此不列为可下载附件；源码仍可构建这些架构。
