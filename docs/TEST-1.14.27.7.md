# 交大课表 1.14.27.7 · A 测试版

显示版本 1.14.27.7，versionCode 94。沿用测试 A 包名 `cn.sjtu.jiaotong_course.slimtest.a` 和测试证书，可覆盖安装 1.14.27.6。

## 修改

- 点击“执行签到”进入当前课程直播后，优先把 PPT／电脑共享视频设为主屏，并选择单屏。
- 适配 2026-10-26 实际检查的 SJTU 播放器控件：`video-layout-control-popper`、主／副屏幕展示（或演示）、原生主副视角交换按钮、单屏选中状态。PPT 缩略图和声道菜单不作为视频切换入口。
- 同时适配手机自动进入的移动播放器：关闭“双视角播放”，打开“视角”菜单，选择 PPT 并确认；核对选中状态、菜单关闭和视频流变化后才开始识别，避免停留在旧摄像头流。
- 读取真实选中状态确认操作，最多尝试一次对应动作；入口等待 12 秒，单次切换等待 4 秒。切换失败提示原因并继续识别当前直播。
- 用户操作布局控件或点击应用中的“手动选择”后，停止自动选择。手动选择跨同次页面导航保留，重新执行签到时恢复自动优先选择。
- 通过播放器自身收起按钮和离开控制区事件减少遮挡。提示区域位于 WebView 上方，不覆盖视频。
- 切换、换流、尺寸变化和缓冲后重建采样状态，至少取得同一画面两次递增播放进度后才截图；PPT 主屏缓冲时不采集摄像头小窗。历史点播选中时先进入直播，不识别回放。
- 提示同时适配浅色、深色和主题切换。签到确认及课程／任务匹配校验继续生效。

## 验证与限制

播放器适配规则来自浏览器中实际渲染的控件与公开 `play-center` 前端源码。浏览器页面为历史点播，仅用于核实控件结构，没有用于签到提交。自动切换与采样规则通过脱敏 DOM 场景和 Flutter 测试验证；实际课堂的新签到 → 当前直播 → 清晰二维码 → 提交成功完整流程仍待 Android 真机验收。

脚本检查：安装开发依赖 jsdom，执行 `node tools/check_attendance_js.cjs`；jsdom 不属于 Android 依赖，不打入 APK。覆盖双画面、已选 PPT、延迟入口、失败回退、手动选择、遮挡收起、缓冲、换流、截图范围及回放排除。
