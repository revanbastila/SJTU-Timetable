# 交大课表 1.14.25 · A 分支后续测试版

以 1.14.24a 为基础继续迭代，沿用 `test/1.14.24a` 分支及原测试 Release 链接；本页的 1.14.24a 旧附件已替换为 1.14.25。测试标签 `v1.14.24a-test` 指向本次源码提交，旧源码提交仍保留在分支历史中。此发布保持 Pre-release，不替代正式 Latest。

## 本次修改
- 右下角悬浮按钮改用此前选定的双日历徽标，动态显示时钟角标、静态显示层叠角标；保留原尺寸、位置、配色适配和点击行为。
- 两种课表模式均移除顶部刷新入口；动态模式的“本周”移至原刷新按钮位置，静态模式不显示该标记。
- 静态课程信息存在项之间留一行空白，保留连续周次区间、单/双周、连堂合并及块内滚动。示例周次为 `2-5周，7-13周`。
- 静态顶部读取远程 calendar.json 当前匹配学期的起止日期；无有效学期时隐藏日期。动态模式继续显示本周日期。
- 按后续补充要求，动态课程方块的地点与教师之间改为两行留白；缺少地点时不额外增加空白。
- 三个设置下拉菜单统一宽度、右对齐、行高、字体、内边距、圆角、选中背景及时间文案，适配六套主题的深浅色。
- Canvas 公告优化增量窗口、离线恢复、稳定 ID 去重、原生缓存更新信号和新公告通知，不显示页面同步进度。

## 安装
- versionName：`1.14.25`；versionCode：`81`。
- 保留 A 测试包名 `cn.sjtu.jiaotong_course.slimtest.a` 和测试签名，可覆盖此前 1.14.24a 测试 A，并与正式版并行安装。
- 常见手机选 `arm64-v8a.apk`；架构不确定选 `universal.apk`。另提供 ARM32 和 x86_64。
- 附件含源码、逐项验收记录、包校验信息和 SHA256SUMS；不含签名私钥、本机缓存或账号凭据。

## 验证与未完成事项
- 初版完成 212 项 Flutter 全套测试；后续动态间距修改后重跑 40 项相关检查通过。Flutter analyze 无问题，四包版本、ABI、签名与 ZIP 完整性核验通过。
- 用户已安排真机测试稍后进行：安装升级、真实 Canvas 新公告、Android 后台调度、网络恢复和系统通知均不能标记为真机验收完成。
- **没有实现严格后台每 2 分钟检查。** 前台名义 2 分钟；后台采用 Android JobScheduler 15 分钟周期、5 分钟 flex，系统省电/休眠可能延迟。没有隐藏常驻通知或滥用精确闹钟。
- **邮箱自动收信尚未接通。** 已确认学校有 read_mails OAuth 接口文档，但 APP 尚无相应授权，还需确认接口覆盖交大邮箱收件箱。没有采集邮箱明文密码，也没有伪造已获取邮件。
- Canvas 实时事件推送尚未开通；现有学生会话未获得管理员事件订阅和转发服务。
- 详细修改、已验证范围和待测清单见附件 `1.14.25-验收记录.md`。
