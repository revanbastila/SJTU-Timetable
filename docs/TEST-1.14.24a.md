# 交大课表 1.14.24a · 并行测试版

这是独立实验分支的预发布版本，用于对比周课表界面，不替代正式版，也不作为 Latest 正式发布。

## 本次界面方案
- 恢复周课表原顶部栏：周次、日期、右侧「本周」标记及教务／Canvas 同步按钮。
- 动态／静态切换移至课表右下角的无文字悬浮按钮；动态显示循环日历图标，静态显示网格图标，点击后图标同步变化。
- 按钮跟随主题色和深浅色模式，保留 48 × 48 点击区域及长按提示。
- 沿用 1.14.24.1 的静态课表周次区间、课程合并与模式记忆；原课程、校历、日程、提醒、小组件和 Canvas 数据逻辑不变。
