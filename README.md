# 交大课表 1.14.27.8 · 测试 A

当前测试版本 **1.14.27.8（95）**。执行签到进入直播后，优先选择 PPT／电脑画面和单屏；同时适配桌面与移动播放器，切换失败继续当前画面，支持手动选择。测试 A 按实际包名读取 `test/1.14.26` 分支的 `updates/test-a.json`，启动与手动检查共用同一渠道。

- [下载测试安装包](https://github.com/revanbastila/SJTU-Timetable/releases/tag/v1.14.27.8-test)
- [修改和验收](docs/TEST-1.14.27.8.md)
- [更新清单与后续发布方式](docs/TEST-UPDATE-CHANNEL.md)

更新文件直接取自测试分支原始文件地址，带防旧缓存参数，不依赖匿名 REST API 额度。设置页显示“更新渠道：测试版”；按 versionCode 判断更新，按设备 ABI 选择安装包，下载后核对大小、SHA-256、实际包名、版本和签名。先公开安装包，最后更新分支清单，避免提示尚不能下载的版本。正式包继续使用正式 Latest。

本版修正部分手机原生直播截图持续黑帧的问题，从 Flutter 实际渲染表面采集，并映射视频截图坐标。独立模拟包在荣耀 Magic8 Pro 上通过 12/12 项真机测试；学校服务端提交与真实课堂完整签到仍待验收。详见本版验证说明。

包名 `cn.sjtu.jiaotong_course.slimtest.a`，沿用测试签名，与正式版独立安装。源码不含签名私钥、账号或会话信息。配置自己的Flutter/Android SDK/JDK和测试签名后可本地构建；不同签名不能覆盖已安装测试包。

**1.14.27.4 及更早版本需先手动覆盖安装一次本版**，之后可在应用内检查测试更新。本机重建：软件目录下 `work/build_114278.ps1`（通用包）或 `work/build_114278.ps1 -Split`（分架构包）；Android 版本名为 1.14.27.8，`pubspec.yaml` 使用 `1.14.27+95`。
